# Financial_analysis

## Propósito
Repositorio de análisis financiero y técnico de instrumentos bursátiles.

## Implementación identificada
Un módulo revisado, `modulos/TechnicalAnalysis.py`, utiliza:
- Streamlit para la interfaz.
- `yfinance` para datos históricos.
- Plotly para visualizaciones.
- Regresión lineal con scikit-learn.
- Medias móviles, MACD y bandas de Bollinger.
- Comparaciones con un índice de referencia.

La existencia de este módulo **no garantiza** que todas sus rutas, datos y dependencias sigan funcionando.
